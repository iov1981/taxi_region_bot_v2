# 🚕 Taxi Region Bot

Telegram-бот для приёма и обработки заявок на поездки между городами и населёнными пунктами Пензенской области, Саратовской области и Республики Мордовия.

Бот автоматизирует приём заявок от клиентов, расчёт расстояния и стоимости поездки, управление заказами администратором и взаимодействие с водителями.

---

## 📌 Возможности

### 👤 Клиент

Клиент отправляет заявку обычным текстом, например:

```text
Пенза Воробьевка 2 человека завтра утром
```

Бот определяет:

* пункт отправления;
* пункт назначения;
* количество пассажиров;
* желаемое время;
* тип поездки;
* расстояние;
* стоимость поездки.

Пример:

```text
Пенза → Воробьевка

Расстояние: 52.5 км
Стоимость: 1 050 ₽
Пассажиры: 2
Время: утром
```

---

### 👨‍💼 Администратор

Администратор имеет отдельное меню:

```text
Последняя заявка
Активные заказы
История заказов
Управление тарифами
```

#### Последняя заявка

Показывает последнюю созданную заявку.

#### Активные заказы

Показывает заказы, находящиеся в работе.

Карточка заказа содержит:

```text
ЗАКАЗ №5

Пенза → Воробьевка
Утро
2 пассажира

52.5 км
1 050 ₽

Статус: 🟢 Новый
Водитель: —
```

Доступные действия:

```text
📞 Телефон
🚕 Водители
❌ Отменить заказ
```

#### История заказов

Позволяет просматривать завершённые и отменённые заказы.

#### Управление тарифами

Администратор может включать и отключать тарифы:

```text
Город
Межгород
```

---

## 🚕 Работа с водителями

Заявки могут передаваться в группу водителей.

Водитель сообщает о готовности взять заказ.

Основная логика:

```text
Новая заявка
      ↓
Группа водителей
      ↓
Водители сообщают о готовности
      ↓
Администратор выбирает водителя
      ↓
Клиентские данные передаются выбранному водителю
      ↓
Заказ выполняется
```

Водитель не получает заказ автоматически только по нажатию кнопки.

Окончательный выбор водителя выполняет администратор.

---

## 🗺 Геокодирование

Для определения координат населённых пунктов и адресов используется геокодирование.

Бот должен корректно обрабатывать:

```text
Пенза
Воробьевка
Пенза, улица Ленина, 25
Воробьевка, Советская, 10
```

### Важное правило

Если пользователь указал конкретный адрес:

```text
Пенза, улица Ленина, 25
```

бот не должен автоматически заменять его на центр населённого пункта.

Если точный адрес не найден, заявка должна завершиться ошибкой геокодирования, а не использовать приблизительные координаты города.

Это позволяет избежать неправильного расчёта расстояния и стоимости.

---

## 💰 Расчёт стоимости

Стоимость рассчитывается на основании:

* типа поездки;
* расстояния;
* действующего тарифа.

Поддерживаются два основных режима:

```text
Город
Межгород
```

Пример:

```text
Расстояние: 52.5 км
Тариф: 20 ₽/км
Стоимость: 1 050 ₽
```

Тарифы хранятся в базе данных и могут изменяться администратором.

# 🛡 Безопасность

В проекте применяются следующие правила:

### Токен Telegram

Не хранится в исходном коде:

```python
BOT_TOKEN = "123456..."
```

Вместо этого используется:

```env
BOT_TOKEN=...
```

---

### Административные функции

Административные обработчики проверяют Telegram ID пользователя.

Обычный пользователь не должен иметь доступа к:

```text
Управлению тарифами
Истории заказов
Активным заказам
Выбору водителя
Тестовым командам
```

---

### Callback-запросы

Все callback-запросы должны получать:

```python
await callback.answer()
```

Callback data должна проверяться до выполнения административных действий.
