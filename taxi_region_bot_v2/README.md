# Telegram-бот поездок: Пензенская область + Саратовская область + Мордовия

Это именно Telegram-бот, а не отдельное приложение.

Клиент просто пишет обычным сообщением:
«Пенза — Саратов, 2 человека, завтра утром».

Бот:
1. сохраняет сообщение;
2. при наличии AI разбирает откуда/куда/дату/время/пассажиров;
3. отправляет карточку заявки администратору;
4. цена Яндекс Go показывается только администратору;
5. клиент получает подтверждение, но не видит внутреннюю цену.

Разрешённые направления на уровне проекта: Пензенская область, Саратовская область и Республика Мордовия.

Для реального автоматического ориентира цены Яндекс Go нужны официальный clid и API key.
